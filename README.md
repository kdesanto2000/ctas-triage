# CTAS Guided Flow — iPhone

This version changes the original form into a one-question-at-a-time guided protocol flow.

## iPhone use

For quick testing, open `index.html` in Safari. For the full app-like experience, host this folder on any free HTTPS static host, open the URL in Safari, then Share → Add to Home Screen. The service worker caches the app for offline use after the first successful load.

## Flow

1. Patient age and assessment phase
2. Special CTAS documentation rules
3. Quick Look / First Look
4. CEDIS / pediatric category
5. Main complaint
6. Clarifying presentation only when needed
7. Relevant first-order modifiers
8. Relevant second-order / complaint-specific modifiers
9. Highest-acuity CTAS result with rationale and assessment trail

This is decision support based on the uploaded Ontario Prehospital CTAS Paramedic Guide Version 2.0 (2016), not a substitute for current clinical standards or medical direction.
